# Bill of Materials

This file lists the basic components used for a simple manual Mercedes-Benz OBD-1 blink-code reader.

| Component | Quantity | Notes |
|---|---:|---|
| Momentary push button | 1 | Used to trigger the diagnostic request |
| Indicator LED / automotive indicator | 1 | Used to observe returned blink codes |
| Resistor(s) | As required | Select appropriately for the indicator circuit |
| Insulated hookup wire | As required | Automotive-friendly insulation recommended |
| Diagnostic test leads / connectors | As required | Must match the vehicle connector safely |
| Heat-shrink tubing | As required | Insulate solder joints and exposed conductors |
| Small enclosure | 1 | Optional but recommended |
| Inline fuse / fused lead | 1 | Recommended protection |

## Notes

The exact connector hardware may differ between vehicles using 8-pin, 16-pin, and 38-pin diagnostic interfaces.

Do not rely on connector shape alone when determining the correct diagnostic connection. Verify the chassis, model year, subsystem, and diagnostic pin before use.
